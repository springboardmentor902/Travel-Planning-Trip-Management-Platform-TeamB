# TripNest – Travel Planning & Trip Management Platform

## About the Internship
Developed as part of the **Infosys Springboard Internship Program 2026**, this project provides hands-on experience in full-stack development, collaborative teamwork, and building real-world software applications.

## About the Project
**TripNest** is a travel planning and trip management platform that brings essential travel information into one place, making trip planning simpler, more organized, and collaborative.

## Key Features
- Trip creation and management
- Itinerary and activity planning
- Destination exploration and management
- Destination-wise weather information using an external Weather API
- Budget and expense tracking
- Secure user authentication
- Collaborative travel planning
- Shared exps, Vlt.

## Technology Stack
- **Frontend:** React
- **Backend:** Java, Spring Boot
- **Database:** PostgreSQL
- **Authentication:** JWT and Google OAuth 2.0
- **External API:** Weather API for destination weather information and Google OAuth 2.0 — Secure authentication and Google sign-in.

## Deployment Options
- **Netlify:** Frontend deployment
- **Vercel + Render + Supabase:** Frontend, backend, and database hosting, respectively

*Deployment options depend on the project's configuration and the services selected.*

## Future Enhancements
- AI-powered personalized trip planning and recommendations
- AI-assisted group expense settlement
- Integrated hotel, flight, and transport bookings
- Secure online payments
- Offline access with automatic data synchronization
- Multilingual support and improved accessibility

## Project Objective
To provide a centralized platform that simplifies travel planning, improves expense management, and enables seamless collaboration among travelers.
